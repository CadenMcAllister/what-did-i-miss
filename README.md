# What Did I Miss?

A personal productivity application designed to help users catch up on information they may have missed by generating concise, organized summaries from their notes and content.

The project focuses on making information easier to revisit and understand without requiring users to read through lengthy documents or manually organize everything themselves.

## Overview

What Did I Miss? is an application meant to simplify how people catch up on information. Rather than having to review everything from the beginning, users can generate summaries that highlight important information and make previously covered material easier to revisit.

The project is designed with an emphasis on simplicity, accessibility, and usability, with an interface intended to make reviewing information straightforward.

## Features

- **Automated Summaries:** Generate concise summaries from supplied content.
- **Markdown Support:** Work with Markdown-formatted notes and documents.
- **Organized Information:** Present summaries in a structured, readable format.
- **Simple Interface:** Prioritize usability and minimize unnecessary complexity.

## Technology Stack

The application uses a combination of frontend development tools, backend services, and data storage to provide its functionality.

- **FlutterFlow:** Application interface and frontend development.
- **Supabase:** Backend infrastructure and data management.
- **Markdown:** Content formatting and storage.

## Running Locally

### Prerequisites

- Flutter SDK
- Access to the project's source code
- Supabase project credentials, if using the connected backend. The Supabase edge function used is attached to this project, so you can bring your own credentials if you want to use your own Supabase project.

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd what-did-i-miss
```

2. Install dependencies:

```bash
flutter pub get
```

3. Configure the required environment variables and Supabase credentials.

4. Run the application:

```bash
flutter run
```
